# 소스 구조

`src/` 아래 API, 파일 조작, 작성자·인증, 카탈로그·검색, 객체 저장과 임시 파일의 책임을 나눈다. `Native/src/`에는 네이티브 핵심, 파일 시스템, 저장소, 데이터베이스, 프레젠테이션과 내부 해시의 책임을 나눈다. 구현과 관련 헤더는 같은 디렉터리에 둔다.

빌드 중 생성한 연결 헤더와 설치된 원본 헤더는 기존의 평탄한 공개 include 이름을 유지한다. `iiFileProvider.SourceLayout`과 `iiFileProvider.Native.SourceLayout`은 새 경로를 검사하며 Qt와 네이티브 구성 요소의 의존 방향은 별도 경계 검사가 유지한다. 구조 변경은 실제 다른 운영체제 실행의 증거가 아니다.

이식 가능한 SQLite 설치 검사는 각 실행에 고유한 빌드 하위 임시 디렉터리를 사용하고 성공 후 정리한다. 다른 실행의 스테이징이나 사용자 데이터를 덮어쓰지 않는다.

macOS 설치 소비자 검사는 실행 시 셸의 `DYLD_*` 검색 경로를 제거한다. 같은 라이브러리 이름을 가진 이전 SDK 설치본 대신 검사 대상 패키지의 라이브러리를 검증하기 위함이다.
