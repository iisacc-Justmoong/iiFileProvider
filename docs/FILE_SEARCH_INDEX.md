# 파일 검색 스냅샷

`iiFileProvider::FileSearchIndex`는 호출자가 전달한 상대 경로와 파일 상세·
분류·검색어를 메모리 SQLite FTS5 색인에 저장한다. 이 객체는 파일을 열거나
경로의 안전성을 판단하지 않는다. 호출자가 소스와 접근 경계를 검증한다.
`iiFileProvider::Catalog`에 포함되며 Qt, iiSDKCore, Society 모듈을 요구하지
않는다. 새 인스턴스는 빈 스냅샷이다.

같은 경로를 갱신할 때 첫 분류 데이터가 제목·키·원문·대기 상태를 소유하며
프레젠테이션 MIME과 검색어를 합친다. 첫 삽입은 true, 기존 경로 갱신은 false를
반환한다. 공백으로 나눈 입력은 리터럴 FTS 접두어로 처리하며 Unicode 악센트는
정규화한다. 최대 질의 길이는 4096바이트, 반환 한도는 1–1024개이다. 연산은
내부 잠금으로 직렬화된다. 검색 결과는 기록한 스냅샷이므로 실제 파일의 존재와
접근 여부는 호출자가 다시 검증해야 한다.

영구 `FileCatalog`는 별도의 커서, 필터 및 변경·게시 기능과 디스크 수명을
가진다. 이 API는 그 데이터베이스를 갱신하지 않으며 두 색인은 서로 다른
수명과 질의 계약을 가진다. iiGlobalSearch는 Society 경로 검증과 비동기 작업을
소유하고 이 객체의 파일 검색 연산을 사용한다.

`iiFileProvider.file_search_index`는 중복 병합, Unicode, 제한, 동시 갱신 및
빈 스냅샷을 검사한다. 운영체제별 앱 실행을 의미하지 않는다.
