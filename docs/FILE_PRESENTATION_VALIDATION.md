## Runtime and source contracts

- Native C++23 owns extraction, persistence, background intake and creation hooks.
  The public header is `iiFileProviderPresentation.h`; no Qt or higher SDK is
  linked into the native component. The installed C++ consumer disables Qt
  package discovery and executes without global dyld overrides.
- Writable Core Channels notify on final successful close; atomic publication
  uses the notifying provider rename/move path. Core's native file test verifies
  the resulting details/preview. Darwin FIFO channels use descriptor-scoped
  SIGPIPE suppression so unrelated provider workers do not turn a broken pipe
  into host termination; pending-signal checks target the writing thread.
- Native tests exercise real bitmap-to-PNG conversion, float32 stereo PCM WAVE
  details/waveforms, escaped Unicode text, actual extended-attribute embedding,
  portable preview bytes/checksums, owner-only companions, original preservation,
  failed attachment preservation, renderer upgrade, recursive external intake,
  restored-mtime edits and Apple composed/decomposed filename lookup.
- Catalog tests preserve strict revisions after annotation edits and reject or
  roll back failed publications. Existing object packages retain portable
  classification and preview documents without private provider state.
- Swift uses the same source-bound presentation schema and native Image I/O.
  Derived writes use reserved staging names plus the shared temporary-file lease.
  Native Files enumeration skips control directories without skipping the
  visible siblings of a control file.
- Android shares the owner's reserved-name rule through DriveStore. Host Java
  tests compile every Android bridge source and exercise public/control naming
  without initializing JNI. Read-only name queries defer native library loading.
- Society intake tests write through a deliberately foreign writer and verify
  automatic details/preview creation and original bytes. Model package identity
  excludes provider control state. A preview's own attribute write preserves
  thumbnail request keys while a later external edit changes them.
- Sync excludes derived presentation/control documents from live replication
  and keeps user classification documents. Direct `drive.stat` finishes
  enrichment before returning a file version for subsequent chunked reads.
  Confined readers/hashes normalize provider-owned attribute ctime using their
  pinned stat/handle fields, with no extra path lookup. A regression proves that
  actual external changes still invalidate a restored-mtime pinned read.
- Native ServerHost shares apply the provider's control rule before pagination,
  including Windows entry validation. A directory containing 270 private preview
  documents still lists its public assets on the first page. Society host
  catalogs and direct reads use the same boundary while private replication
  retains user annotation documents.
- Helper supplies a bounded IISC domain renderer without a provider dependency
  on iiSharedCanvas. The shared preview renderer preserves exact mask coverage
  at native size; reduction remains smoothly sampled. Helper tests compare real
  PNG pixels, regenerated previews and original strict save conflicts.
- Society's GUI consumer compiles the actual product DirectoryLocation and GUI
  regression sources, loads the actual QML through installed LVRS, displays the
  actual preview data URL, and exercises Space/Escape and rapid selection changes.
  It is an ordinary executable in the SDK build tree and creates no second
  Product application bundle.

## Evidence boundaries

The macOS host executes native C++/Swift and the Qt GUI consumer. The Container
iOS package contract compiles/links the unsigned iPhoneOS native Files bridges
and extensions. Android checks compile Java against SDK 35 and native arm64
objects against installed NDK 26.1 using its C++23 draft spelling (`c++2b`);
these are compile checks, not device execution. iOS C++ object checks likewise do
not constitute an iOS app or device run. Windows, Linux and WASM runtime execution
was not performed for this change.

Image/document decoding is admitted up to 32 MiB; unsupported, corrupt and
over-budget assets retain file details and an honest information card. The
source-only Swift bridge has fewer decoders; a C++ consumer may upgrade its
information card once. Native attribute availability is filesystem-dependent;
the portable companion is always the transportable representation.

Space preview is implemented in Society. The provider uses Apple's native
Image I/O and Quick Look Thumbnailing backend where available, but does not
register a new system Finder Quick Look extension for IISC. External intake
requires a live storage-owning process/daemon. No active installed app or real
Society drive was restarted, migrated or replaced to obtain these fixture results.

# Deterministic bridge cache validation

The native presentation regression drains the automatic creation queue before
replacing an unsupported file's information card with a source-only bridge
record. This isolates the subsequent synchronous upgrade/cache assertions from
the legitimate asynchronous intake of that same newly created file.
