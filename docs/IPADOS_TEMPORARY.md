# iPadOS 임시 파일 임대 경계

iPadOS 앱은 자신의 데이터 컨테이너를 열 수 있지만 `/private/var/mobile/Containers` 같은 상위 시스템 디렉터리를 읽기용으로 순회할 수 없다. TemporaryLease는 이 플랫폼에서 운영체제가 지정한 `HOME` 컨테이너를 먼저 고정하고 그 아래의 각 구성 요소를 `openat`·`O_NOFOLLOW`로 연다. `/var`와 `/private/var`의 운영체제 경로 표기는 컨테이너의 정규 경로와 비교한다.

컨테이너 내부의 심볼릭 링크·상위 경로 탈출·변조된 잠금 파일은 계속 거부한다. 잠금 파일의 빈 내용·정규 파일·단일 하드 링크·inode 검사와 공유/독점 임대 계약은 유지한다. macOS·Linux·Windows의 기존 경로 정책은 바꾸지 않는다. 앱 컨테이너 밖의 경로가 읽기 가능한 상위를 제공하지 않는 경우 기존 거부를 유지한다. 외부 문서 제공자의 보안 범위 경로에 대한 별도 신뢰 루트 전달은 이 변경에 포함하지 않는다.

`tests/temporary_anchor.cpp`는 상위 디렉터리가 탐색만 허용하고 읽기는 허용하지 않는 fixture에서 컨테이너 접근을 검사한다. 동일 경로의 루트부터 순회가 실패하는지, 내부 링크와 경로 탈출이 계속 거부되는지도 검사한다. `tests/temporary_lease.cpp`의 공유·독점·프로세스 간 잠금 검사를 함께 실행한다. 실제 iPad 문서 저장·재열기는 소비 앱의 기기 진단으로 별도 확인한다.
